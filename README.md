# 算命 · 中式与西式占卜的实验场

一个纯前端的网页项目，反复尝试「中国的卦」和「西方的牌」到底能不能真正合在一起。
先后做过四个形态，现在留在仓库里的是：

| 入口 | 是什么 | 时长 |
|---|---|---|
| **`web/story.html`** | **《一世》互动版** —— 掷六卦走完一生，七个结局 | 约 4 分钟 |
| `web/grey.html` | 灰底原型 —— 三片证据自己合，验证「读得懂吗」 | 约 4 分钟 |
| `web/epoch.html` | 《一世》游戏版 —— 命盘、注码、场外升级 | 约 8 分钟 |
| `web/raid.html` | 《命市下潜》—— 搜打撤 | 约 3 分钟 |
| `web/life.html` | 《三百六十行》—— 五个行当 | 约 4 分钟 |
| `web/index.html` | 《问一卦，抽一张》—— 最初的一局仪式 | 约 5 分钟 |

## 怎么跑

大部分页面双击就能开；用到 `localStorage` 存档的（`story` / `epoch` / `raid` / `life`）需要起一个本地服务：

```powershell
cd web
python -m http.server 8811
# 打开 http://127.0.0.1:8811/story.html
```

# 问一卦 · 抽一张

掷六爻成卦，**卦不回答你，卦只定这一局的规矩**；再抽三张塔罗，你只能留一张作为答案。
一局约五分钟的网页小游戏，中西两套占卜在同一张桌上对赌。

## 怎么玩

打开 `web/index.html` 即可（无需安装、无需联网、无需构建）。

流程五步：

1. **起念**：选一个方向（事业 / 感情 / 财运 / 身心 / 自身），或写一句话。
2. **起卦**：三枚铜钱掷六次，背为阳、字为阴；和数 6 老阴、7 少阳、8 少阴、9 老阳。自初爻而上成卦，得本卦、动爻与变卦。
3. **卦规**：内卦（下卦）定「你能取哪张」，外卦（上卦）定「取到之后如何」，动爻定「这一局稳不稳」。
4. **定应**：抽三张塔罗，落在天（时机）/ 地（处境）/ 人（可为）三才之位。按卦规只能选合法的牌。
5. **判词**：以应牌五行对用神五行（生克），叠外卦扭转与动爻乘数，得等级、判词、机，并生成可保存的签卡。

## 这一局的规则

### 内卦：你能取哪一张（8 种）

| 内卦 | 规则 |
|---|---|
| 乾 | 三才皆可取（天行健，取舍在你） |
| 坤 | 只可取「人」（地势顺承，成事在人） |
| 震 | 只可取「天」（雷动之初，先觉者先动） |
| 巽 | 只可取「地」（风行草偃，入乎其中） |
| 坎 | 只可取水、金之牌（险中求，取润下与从革） |
| 离 | 只可取火、木之牌（明两作，取炎上与生发） |
| 艮 | 不可取「地」（艮止于中，中位不宜） |
| 兑 | 须取与所问同象、或生其所问之象的牌（同气相求） |

### 外卦：取到之后如何（8 种）

| 外卦 | 扭转 |
|---|---|
| 乾 · 天予 | 判为上吉以上，再进一等 |
| 坤 · 承载 | 得分减半，但永不落凶 |
| 震 · 雷动 | 可重抽一张牌 |
| 巽 · 风行 | 可交换任意两张牌的位置 |
| 坎 · 水险 | 应牌既定，再折一分 |
| 离 · 照见 | 应牌与所问同象，加二分 |
| 艮 · 止限 | 只能在一、二张中取 |
| 兑 · 悦终 | 应牌为第三张，加二分 |

### 动爻

- 六爻皆静 → 定数：得分 ×1.2，但无从改易
- 动爻一二 → 气机微转
- 动爻过半（≥3）→ 局势未定：可重抽一张，得分 ×0.8

### 判定

**用神 = 内卦五行**（乾兑金、震巽木、坎水、离火、坤艮土）。以应牌五行对用神：

| 关系 | 分 | 意 |
|---|---|---|
| 应生用神 | +3 | 得助 |
| 比和 | +1 | 同气 |
| 用神克应 | +1 | 可制 |
| 用神生应 | −1 | 走泄 |
| 应克用神 | −2 | 受制 |

### 越规：不给你兜底，把代价摆出来

三张牌**永远都能点**。卦所不许的位置也能取，那叫**越规**，判定另扣二分。

初版曾用「卦规与手牌不相容时替你强取地位置」兜底，实测结果很糟：**64.1% 的局里玩家只有一条路可走，75% 的局里没有任何操作手段**——那不是游戏，是执行。改成越规之后：

- 每局至少两条路：**守规取那一张**，或**越规取另两张**
- 守规最优与越规最优的分差常常只有 2～3 分，所以越规有时是对的
- 实测 **11.6% 的局里越规才是正解**——约九局一次，赌得有道理
- **7.7% 的局卦不许、手中无一可应**（如内卦坎而手无水利之牌），此时越规是唯一走法，破戒本身成了卦意

### 复盘：把隐藏的技巧露出来

判完之后必须告诉你「本可以更好」，否则玩家永远学不会：

> 守规最优是「地」位「魔术师」水（得助 +3）；你取「天」位「太阳」火（受制 −2），差 **5** 分。
> 此卦用神为 **木**——最贵的是「水」（生用神）与「木」（比和）；「木」所生之「火」会泄你的气。

取到最优时只给一句「此局没有更好的走法」。越规时另给一句判词，说明这一戒破得值不值。

### 卦限

定应屏会显示此卦的松紧，玩家很快会记住「乾卦很松、坎卦很紧」：

| 可取张数 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|
| 卦限 | 松 | 中 | 紧 | 绝 |

等级：上上 / 上吉 / 中吉 / 中平 / 下 / 下下。守规取牌的实测分布偏「多为小吉」：中吉以上约六成。

|---|---|---|---|
| 结构 | 一场仪式：一把定输赢 | 搜打撤：一次下潜，随时可撤 | 人生线：五种行当，逐层下注 |

| 决策 | 守规取哪张 / 越不越规 | 每层继续还是撤、带什么 | 每行命脉与反噬的取舍 |

### 《三百六十行》：一套循环，五份配置

```powershell
cd web
python -m http.server 8811
# 打开 http://127.0.0.1:8811/life.html
```

同一个「问事—逐层下注—收手/翻车」循环，五个行当的差别在**命脉**、**风险曲线**与**专属机制**。
关键设计：**每一行里，卦降低的是不同种类的不确定性**——这是让 360 行不沦为换皮的地方。

| 行当 | 命脉 | 卦降的是 | 专属机制 | 登峰 |
|---|---|---|---|---|
| **古玩** | 眼力 | 真伪 | 赝品成交只值一成 | 单局成交 ≥ 200 |
| **摸金** | 阳气 | 凶险 | 每层耗阳，阳气尽则被迫撤离 | 活着走完六层 |
| **经商** | 信用 | 时机 | 杠杆：收益 ×2、反噬 ×1.6 | 杠杆局 ≥ 300 |
| **攀亲** | 颜面 | 人心 | 翻车只丢脸、清好感，不掉命 | 单局好感 ≥ 5 |
| **科研** | 经费 | 方向 | 翻车只损一半，可继续 | 走到第五层且未栽 |

**结局**：集齐三个行当的登峰即人生赢家——而结局的落点是「最后一件事，你没有问卦」。
算命登峰造极，是不再需要算命。

### 《一世》：出生一卦，六节人生

```powershell
# 打开 http://127.0.0.1:8811/epoch.html
```

**一世 = 一局。** 出生掷一卦定命格，六节人生定结局，**死不是失败，是结算**。

**出生卦给两样东西**：卦判（上上～下下，这一世的底色）+ 用神五行（内卦五行，你命里属什么）。

**命盘是四条线，不是一个数。** 卦不给「吉凶」，它给**财 / 名 / 缘 / 安** 四路各自的旺衰：

| 用神与某路 | 读法 | 系数 |
|---|---|---|
| 用神生它 | 气都往这里走 | ×1.40 |
| 同气 | 顺手 | ×1.25 |
| 它生用神 | 出得多、留得少 | ×1.00 |
| 用神克它 | 你压得住，但压住的不是你的 | ×0.85 |
| 它克用神 | 这一路与你相争 | ×0.50，且添一分伤 |

**四路必然不均**——用神只有一个，而四路分属金火木土，落在生克图上必然有旺有衰。**财旺则名必弱**，这是结构，不是数值调出来的。所以「哪个选择最优」取决于你要哪一种人生：要富家翁就吃伤，要儿孙满堂就弃财。

**岁运让同一卦在不同年纪读法不同。** 六节各有岁运五行（木火土金水土），与用神生克决定当节基调：运来生你 ×1.15、当运 ×1.25、你泄于运 ×0.90、运来克你 ×0.85。

**问卦出两象，不出结论。** 真实起卦从来给两个卦：**本卦**（现在的局势）与**变卦**（事态会变成的样子）。两象的判常常相反——「先好后坏」「先难后成」正是读易最难的地方。

所以每节问卦后你拿到的**不是一个结论，是两个互相矛盾的结论**，必须自己裁决：

- **信本卦** → 早收，用本卦的判
- **信变卦** → 等到底，用变卦的判
- **六爻皆静** → 无变卦，数定，你没得选

实测 20000 次起卦：17.8% 卦静无变卦，30.2% 两象倾向相同，**51.9% 两象倾向相反**。

### 中西结合就在这一步：卦说缺什么，牌说有什么

**卦给「用神」**——本卦内卦的五行，代表你缺什么。
**牌给「资源」**——三张塔罗择一为「应」，每张牌带五行（星体/星座归属）与地支。
**生克决定这一象的强弱**：应生用（得助）→ 上吉；比和 / 用克应 → 中吉；用生应（走泄）→ 中平；应克用（受制）→ 下。

因为本卦与变卦的内卦不同，**用神也不同**——同一张牌常常对本卦有利、对变卦有害。实测：有变卦的局面里，**45% 两象强弱相同，55% 一利一害**。

于是选牌和选象是**一对互相牵制的决定**：你手里这三张牌，决定了该信哪一象。这就是中西两套系统真正的咬合——不是并排放着，是**同一张牌被两个卦同时检验**。

典型的「先好后坏」：本卦**雷天大壮**「利贞。」（守则吉），变卦**雷泽归妹**「征凶，无攸利。」（动则凶）。读得出这一层的人会早收。

**界面只给卦辞原文，不给吉凶数字。** 你得自己读。「征凶，无攸利」和「元亨利贞」，哪个该信？

**卦只说这一步怎么走，不说结果好不好。** 所用之象的卦辞推出宜/忌，而**卦意只改折损率，不改收益**：

| 卦说 | 宜 | 折损怎么变 |
|---|---|---|
| 利涉大川 / 利有攸往 | **宜进** | 押重时 38%→21%，押轻时反而略增 |
| 勿用 / 无攸利 / 不利有攸往 | **宜守** | 押轻时 8%→6%，押重时 38%→70% 且额外添一分伤 |
| 利见大人 | **宜借** | 缘旺则降到 60%，缘衰则涨到 140% |
| 元亨利贞（无嘱托） | 宜常 | 不变 |

（`EPOCH.readImperative()` 按卦辞正则判定，实测 64 卦：宜进 15、宜守 9、宜借 4、宜常 36；宜常者再按卦判强弱补成进或守。）

**卦会不应验，动爻就是变数。** 六爻静 → 应验 88%；一二爻动 → 68%；**动爻过半 → 只有 45%**。不应验时整个卦反过来：说「宜进」的其实是「宜守」。**界面只显示动了几爻，不显示准不准**——信多少要自己掂量。

**问卦稀缺**：每世 4 次额度，人生 6 节。哪四节问是判断。

### 实测：按卦走真的稳赢吗？（`node tools/sim-epoch.mjs`，每种打法 4000 世）

| 打法 | 平均价值 | 死亡率 |
|---|---|---|
| 按卦走（问卦并服从） | **471** | 11.6% |
| 按卦走，但看自己的伤（懂命） | 458 | **7.0%** |
| 按卦走，但卦乱就不信（多疑） | **478** | 10.6% |
| 不问卦、全押重注 | 432 | 33.5% |
| 不问卦、全押轻注 | 328 | 2.1% |

结论：**盲从卦意不是最优**（478 > 471 > 458），三种「聪明打法」的差距虽小，但死亡率能差近一倍。卦的价值是**让你在别人不敢下注时敢下注**，不是替你决定。

结局分布（按卦走 2000 世）：无名之人 58%、落魄先生 12%、一代宗师 11%、富家翁 10%、半仙 5%、儿孙满堂 4%。

**负负得正**：判为「下/下下」的命走摸金、经商两险行，系数拉到 **×1.4** 且免一分伤；反之好命走险行是 ×0.9 白瞎。**坏签不劝你重开，它给你另一套 build。**

**改运**：重掷出生卦或某节之卦，各耗一次改运（由场外升级供给，用一次少一次）。

**六节**：17 学徒 / 24 入行 / 31 立身 / 38 转运 / 47 翻身 / 56 收摊。每节：选行当 →（可选）问卦 → 选注（轻/中/重，×0.6 / ×1.0 / ×1.6，折损 8% / 20% / 38%）→ 落定。

**结算**：伤满 10 即亡，或六十岁收摊。

```
人生价值 = 财 + 名×2 + 缘×2 − 伤×5
资财     = ⌊价值 / 12⌋ + 3      （保底也有）
```

资财买四项场外升级，**永久留给下一世**：前世记忆（问卦额度 +1）、改运（起始改运 +1）、家学（起始财 +20）、祖上积德（出生卦可重掷）。

六种结局：半仙 / 富家翁 / 一代宗师 / 儿孙满堂 / 落魄先生 / 无名之人。

### 《命市下潜》：投入换信息

```powershell
cd web
python -m http.server 8811
# 打开 http://127.0.0.1:8811/raid.html
```

三段对应搜打撤：

- **搜**　每深一层掷一爻、得情报。四维情报（向 / 势 / 时 / 险）各有「深处才见」的门槛——牌材再好，也读不出还没发生的事。
- **打**　六爻成卦才见真章：从一路抽到的六张牌里取一张为「应」，用神对生克，判出等级，等级决定情报兑现系数（上吉 ×1.8，中吉 ×1.3，中平 ×1.0，下 ×0.7，下下 ×0.4）。
- **撤**　任何时候都能封卦。未成卦就撤，情报只兑九成（未经卦验）。

三件升级对应你的提案：**铜钱**（重掷一爻的次数）、**牌材**（每层多读一维情报）、**法器**（−3% 反噬 / 击穿保底）。全部标的、商号、传闻均为虚构。

### 带出来的是四种东西，各接一个系统

只有「签」会单调——一条轴（卦 × 牌），长得一样、用法一样。所以战利品按**用途**分四类：

| 收获 | 类别 | 接的系统 | 规则 |
|---|---|---|---|
| **签** | 图鉴 | 收藏 / 八宫 | 六爻成卦、受判之后才留下；品阶随判定，稀有度随动爻数 |
| **牌** | 图鉴 | 牌册 | 撤离时带回，22 张可集齐 |
| **护身符** | 消耗 | 局内保命 | 击穿时替你受一次；**带进去没用掉可以再带出来** |
| **长明灯** | 消耗 | 局内增益 | 点起后本局每层多读一维情报 |
| **朱砂 / 澄心纸** | 材料 | 合成 | 砂 3 + 纸 1 → 画一道护身符 |
| **碎签** | 残片 | 陈列 | 击穿且已到第 3 层以上才留；兑不了钱 |

四类各自对应：**图鉴**（收集欲）、**消耗**（进局前带什么，一局两格的取舍）、**材料**（垃圾有用）、**残片**（失败留痕）。

**除碎签外，所有东西只有活着带出去才算**——击穿则全失。所以捡到的护身符是「现在就用，还是留着下局用」的两难。

**签只在卦成之后才有。** 早早撤离只有钱和牌，没有签——想收藏，就得潜到底；潜到底会死；死了留碎签。收藏欲本身就是风险来源，不需要额外数值诱饵。

**八宫**：按上卦分八宫，每宫八卦。集齐一宫 → 兑现 +2%，八宫集齐 +16%。

### 风险曲线（模拟 2 万局，`node tools/balance.mjs`）

```
裸装    撤离深度 1→6：期望净得  24 / 40 / 55 / 55.6 / 46 / 41    最优第 4 层
满配    撤离深度 1→6：期望净得  29 / 47 / 68 / 75 / 73 / 80      最优第 6 层
```

**「越深越好」不成立**（裸装到第 6 层期望反而下降），而**升级把安全边界往外推**——装备不是给你更多钱，是让你能安全走得更远。这一条是配平的核心判据。

## 这么多术数，怎么合理融合

### 原则一：五轴分工，每套术只答它擅长的那一轴

每一套术数本质上都在回答**一个特定类型的问题**。混在一起是乱炖，分工才叫融合。

| 轴 | 问什么 | 中式 | 西式 |
|---|---|---|---|
| **命** | 你是谁、底子如何 | 八字 · 紫微 | 出生星盘 |
| **事** | 这件事成不成 | 六爻 · 梅花 | 塔罗 · 占星骰 |
| **时** | 什么时候做 | 岁运 · 流年 · 奇门 | 行运 transit |
| **人** | 和谁做 | 合婚 · 合盘 | synastry |
| **方** | 在哪做 | 风水 · 奇门方位 | 方位占星 |

判据：**塔罗不能告诉你八字用神是什么，紫微也不能告诉你抽到哪张牌。** 越界即失据。

### 原则二：不重叠——各答一半，不抢同一个问题

这是本项目认为最关键的一条。

如果六爻和塔罗都回答「这一节好不好」，那只能比谁更准，**两套系统争同一个问题就退化成冗余**。

正确的分工是它们回答的**根本不是同一个问题**：

> **中式问「该不该动」**——卦辞说宜进、宜守、宜借。
> **西式问「动不动得动」**——塔罗的五行与卦的用神生克，看手里有没有力。

合起来才是完整判断，且天然形成四象限：

| | 手里有力 | 手里无力 |
|---|---|---|
| **天时该动** | 天时在手，牌也有力 → 可押重 | 天时对，没牌 → 押了也白押 |
| **天时宜守** | 有牌，天时不与 → 留着，别急 | 天时不与，也没牌 → 别动 |

实测 30000 次：**29.7% / 12.2% / 30.7% / 27.3%**——四象限都常见，不是摆设。

### 原则三：同一符号指向同一底层对象

融合的技术前提是**有对应表**，让不同体系的符号指向同一个东西：

- 十二星座 ↔ 十二地支（七政四余的黄道十二宫命名）
- 十星体 ↔ 十干（日木火土金水，白道上的十政）
- 四元素 ↔ 五行（西方炼金术本有第五元素 aether，正可补「金」）
- 22 张大牌 ↔ 十干 + 十二支（数量恰好相合）

**没有对应表，融合就只是并排展示。**

## 为什么这两套能放在一张桌上

映射分三档，前两档有出处，第三档是设计：

**一、十二星座 → 十二地支（同源）**
中国七政四余（果老星宗）本有「黄道十二宫」命名，与西方星座一一对应：
戌白羊、酉金牛、申双子、未巨蟹、午狮子、巳室女、辰天秤、卯天蝎、寅人马、丑摩羯、子宝瓶、亥双鱼。
牌上的「地支应期」即出于此，不是为游戏编的。

**二、七政 → 五行（同源）**
日月五星在中西两边是同一组天体。中国称七政、七曜，其五行归属（木星木、火星火、土星土、金星金、水星水、太阳火、太阴水）是原有的。
塔罗的星体/星座归属用 Rider–Waite 与 Golden Dawn 的通行对应（8 力量=狮子、11 正义=天秤）。

**数量上的巧合，也是选这副牌的理由**：十星体 + 十二星座 = 二十二张，恰是十干加十二支之数。

**三、属本项目设定**
风象（双子/天秤/宝瓶）归木；三王星按五行性质类推（天王金、海王水、冥王火）；五域（事业木、感情火、财运金、身心土、自身水）的五行归属；以及全部「局规」文本——皆为游戏设计，非学术定论。

## 下一步可以做的

按「杠杆/成本」排序，前两条才是真正的游戏性来源：

1. **三问一命（roguelike 结构）**——一局连问三事，判词等级折算「机缘」，机缘可在下一问买交换/改牌；累积三劫则本局命尽。这是把「一局一次的随机」变成「一条有得失的曲线」，目前最缺的正是这个。
2. **赌注式越规**——越规除扣分再记一劫（可跨三问累积），让「破戒」成为要权衡的资源，而不是单纯的价格。
3. **牌义按所问分化**——同一张牌在事业与感情各有读法，判词从模板变成回答。
4. **双人对赌**——同问一事，各取一应，比谁判得高；天然适合分享传播。
5. **手感**——「一次掷完」省掉六次各 640ms 的等待，加音效。
