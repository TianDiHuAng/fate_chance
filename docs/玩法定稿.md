# 《一世》玩法定稿 v2

> 两轮共 18 个子智能体（4 提案 + 2 评审 + 收敛 + 红队 + 定稿；4 拆解 + 2 评审 + 收敛 + 红队 + 定稿）逐步收敛。
> v1 的致命漏洞由红队指出，v2 修补。本文是实现依据。

## 一句话

一局六节，每节**摇一卦、断一次、押一注**——
**卦只给证据（指哪张、多可信、忌讳什么），哪张卡得势由你判断，判错即押空。**

## 一局流程（20 击，约 4 分钟）

六节：17 / 24 / 31 / 38 / 47 / 56 岁。月令按 木 → 火 → 土 → 金 → 水 → 土 固定轮换。

### 0 出生（2 击 · 40 秒）
长按三钱摇两组下卦，**8 选 1 定本命**：每张 = 下卦 + 一张塔罗大阿卡纳 + 财 / 名 / 缘 各 +10 的起手偏向。
本命五行，就是你一生的行当。

### ① 摇（1 击 · 长按 0.8 秒）
三钱落定 → 本节上卦。**本命下卦 × 上卦 = 六十四卦真名**，出象辞一句、白话一句。
同屏给三样：

| 证据 | 来源 | 读法 |
|---|---|---|
| **向** | 阳卦（乾震坎艮）指本卦；阴卦（巽离坤兑）指变卦 | 在对应卡上盖「卦指」章 |
| **性** | 动爻 0 / 1–2 / 3+ → 静 / 动 / 乱 | 静可信、动含糊、乱反指 |
| **忌** | 乾震忌轻 · 坎艮忌重 · 坤巽离兑忌逆 | 各挂一个已有机制 |

旁边显示本节**月令**与两张卡的 **旺 / 平 / 死**。

### ② 断（1 击 · 这一步是玩家自己在算）
只给两张卡：**本命行当**、**之卦行当**。问「今年谁得势」，点一张。
**不公布答案。**

### ③ 注（1 击）
轻 / 中 / 重，按住预览会掉几格命灯。

### ④ 落（0 击 · 自动）
翻一张塔罗，只报结果：牌名 + 一句 + 「进账 +52 / 折损 −18」。
得势揭晓，批语补原因：「金在亥月是死的，卦却指金——乱卦，你该反着看。」

## 玩家只需同时握五个概念

1. **本命** —— 你押的那条路（一个行当、一条主线）
2. **旺衰** —— 卡上只一个字：旺 / 平 / 死
3. **卦话** —— 盖「卦指」章的那张 ＋ 性（静 .8 / 动 .55 / 乱 .3）
4. **忌** —— 忌轻（轻注只得一半）／忌重（重注押中多掉 1 命）／忌逆（逆着卦押，中了只得八成）
5. **注码 = 命灯** —— 轻 0 / 中 1 / 重 2.5，12 格满即死

```
押中 = B × 注码           B = 40/50/60/70/80/90（按节涨）
押空 = −0.35 × B × 注码
伤   = 注码伤（0 / 1 / 2.5）
p    = 性（.8 / .55 / .3）± 0.1（卦指那张旺 +、死 −）
```

**五行当**：金古玩（财）· 火书院（名）· 木攀亲（缘）· 土置产（中则回 2 命）· 水摸金（财×1.2、伤 +0.5）
**结局**：财 / 名 / 缘 ≥ 260；三线各 ≥ 120 且伤 ≤ 6 半仙；伤 ≥ 9 且财 < 150 落魄；伤满即夭。

## 64 卦凭什么有个性

- **名是真的**：下卦 = 本命（一局固定，等于一宫），上卦是你摇的。一局逢六个卦、六个之卦，结算进卦册。
- **向**由阳卦 / 阴卦定，**忌**由上卦三族定，**性**由动爻数定——**全是真六爻，不是贴纸**。
- 每卦一句 6–10 字谶，对着忌写：「坎·习坎入穴｜忌重」。**先记脾气、后记卦名**，正是算命先生的认识顺序。
- 换本命 = 换宫 = 换一整套卦，第二局不是同一副。

## 玩家在哪里「自己算」

**断。** 屏上给三份证据：卦指哪张、那张旺还是死、这卦多可信。

- 旺 + 静 → 押它、压重
- 死 + 乱 → 反着押——但忌逆只赔八成，得算值不值
- 动卦遇平旺 → 谁也不敢押，只能轻注买过

**这是占卜里唯一不能外包的一步。**

## 主控追加的两条修改（本轮补齐）

### 改动一：卦与月令必须经常打架
若「卦指」总是与「旺」一致，断就退化成读一个数——红队指出的「p 只有 9 个取值，两局背熟」正是这个病。
所以固定一条：**月令轮换必须保证「卦指之卡为死」的局面约占四成**。
此时断才有真取舍——**信卦（吃忌逆八成），还是信月令（吃卦的反噬）**。
这一条是配平的硬指标，实现时必须测量。

### 改动二：不印百分比
「性」只说**静 / 动 / 乱**，批语里也不出现 80% / 55% / 30%。
玩家靠经验估——**背熟一个近似值是知识，不是退化策略**；但屏幕上印出精确数字，就变成了算术题。

## 砍掉了什么（v1 → v2）

5 张行当卡 → 2；3 张塔罗 → 1 张且只做结算；90/70/50、1.3/0.8、命倍率、时倍率、身/变/兆系数、伤系数全部删除，换成旺衰 ±0.1 一条；节气/起卦/抽牌三步自动并成一次长按；重摇、重问、38 岁大运整段删；财名缘常驻条改成节末一行箭头。

## 红队留给下一轮的四个风险

1. **表格化** —— p 若可精确计算，两局背熟后只剩调注。→ 用「不印百分比」+「卦令常打架」压住。
2. **命灯是唯一硬约束** —— 最优可能退化成「前四节轻注、后两节梭哈」。
3. **4 分钟装不下感情** —— 谶记不住，卦册就成了图鉴，不是命。
4. **批语写不好，旺衰仍是贴纸。**

## 下一步：先做灰底原型，别再画设计

三次评审的共同结论：**这套设计已经够好了，问题是没人验证过普通人能不能读懂。**
用户说过「还是没明白」——这不是靠再想能解决的。

**灰底黑字原型验收**（无美术，5 个没读过易经的人各跑 3 局）：
1. 每节决策 ≤ 15 秒
2. 能说出「为什么押重」里，卦 / 月令 / 命灯 至少两条
3. 能复述上一节的卦名或它的忌

**数值验收**（4000 世模拟）：
全跟卦 / 全信月令 / 看命灯行事，三种打法**人生价值差 < 15%、死亡率差 > 8%**。
任一打法碾压，说明还藏着最优解——**回去调倍率，别再加系统**。
