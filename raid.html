    说明

    这是一个搜打撤结构的占卜小游戏：你带着香火钱下潜一次，一路读出关于某个 虚构标的的命理情报，随时可以封卦撤离，也可能被命数击穿、情报尽散。

    三段

    • 搜　每深一层，掷一爻，读出若干维情报（向 / 势 / 时 / 险）。牌材质越高，每层读得越多。
    • 打　六爻成卦时才见真章：从一路抽到的牌里取一张为「应」，用神对生克，判出等级，等级决定情报的兑现系数。
    • 撤　任何时候都能封卦。撤得早稳而小，撤得晚厚而险——死，永远是你自己选着继续的。

    投入换什么

    • 铜钱等级　重掷一爻的次数。掷坏了可以重来，改的是卦，不是运气。
    • 牌材　每层多读一维情报。这是「投入越多，命运的信息越多」的直接实现。
    • 法器　降低反噬概率，并在击穿时保住一部分签金。

    你带出来的是什么

    • 签　六爻成卦、受判之后才留下的一枚签：卦名、应牌、品阶（金 / 银 / 铜 / 木 / 纸 / 灰）、稀有度（常 / 稀 / 珍 / 绝）。签只在卦成之后才有——想收藏，就得潜到底。
    • 牌　一路抽出的大牌，撤离时带回「牌册」，二十二张可集齐。
    • 护身符　击穿时替你受一次，用掉即无；带进去没用掉，可以再带出来。
    • 长明灯　点起后，本局每层多读一维情报。
    • 朱砂 / 澄心纸　画符的料。三份朱砂配一张纸，可成一道护身符。
    • 碎签　被命数击穿、且已经到第 3 层以上，会留一枚碎签。兑不了钱，只能压在匣底。

    除碎签外，所有东西只有活着带出去才算——击穿则全失。集齐一宫（上卦相同的八卦）兑现 +2%。

    兑现

    签金 = 标的价值 × 情报完整度 × 深度 × 判定系数（未成卦即撤离另有折价）。 情报越全、潜得越深、卦判越好，兑现越高；被击穿则归零（法器可保住一部分）。
