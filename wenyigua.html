说明

这是一个五分钟的小游戏，不是算命服务。它的全部乐趣在于：卦给你的规矩，往往和你想抽的那张牌相反。

怎么玩

  1. 选一个方向（或写一句话），起念。
  2. 掷三枚铜钱六次，自下而上成卦。你得到本卦，以及可能出现的动爻与变卦。
  3. 卦的内卦（下卦）决定这一局你能取哪张牌；外卦（上卦）决定取到之后如何算；动爻决定这一局是「定数」还是「局势未定」。
  4. 抽三张塔罗，分别落在天（时机）、地（处境）、人（可为）三才之位。
  5. 按卦规只能选合法的牌作为「应」。选完落定，看生克。

为什么这两套能放在一张桌上

不是硬凑的对应，有两处是真有来历的：

  • 十二星座 → 十二地支：中国七政四余（果老星宗）本就有「黄道十二宫」命名——戌白羊、酉金牛、申双子、未巨蟹、午狮子、巳室女、辰天秤、卯天蝎、寅人马、丑摩羯、子宝瓶、亥双鱼。牌上的地支应期即出于此。
  • 七政 → 五行：日月五星在中西两边是同一组天体，中国称七政、七曜，其五行归属（木星木、火星火、土星土、金星金、水星水）是原有的，不是我们分的。

塔罗的星体/星座归属采用 Rider–Waite 与 Golden Dawn 的通行对应（力量=狮子、正义=天秤）。十星体 + 十二星座 = 二十二张，恰是十干加十二支之数——这是选它作牌组的原因。风象归木、三王星按五行性质类推，属本项目设定。

判定

「用神」取内卦五行（乾兑金、震巽木、坎水、离火、坤艮土）。以应牌五行对用神：应生用 +3（得助）· 比和 +1 · 用克应 +1（可制）· 用生应 −1（走泄）· 应克用 −2（受制）。再叠外卦扭转与动爻乘数，得六等：上上 / 上吉 / 中吉 / 中平 / 下 / 下下。

要紧的一句

卦规与塔罗归属中，凡标为「设定」者皆为游戏设计，非学术定论。本作不提供任何医疗、投资、法律或人生决策建议——它只提供五分钟的犹豫。
