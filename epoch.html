说明

一世就是一局。出生卦定命格，六节人生定结局，死是结算不是失败。

一、出生卦

掷六爻成卦，得两样东西：卦判（上上～下下，你这一世的底色）与用神五行（内卦五行，你命里属什么）。

命格五行与行当五行相生相克，决定适配。行当生你最顺（×1.25），行当克你最逆（×0.85）。

二、命盘：四条线，不可能全旺

卦不给「吉凶」一个数，它给的是财 / 名 / 缘 / 安 四条线各自的旺衰。

用神只有一个，而四路分属金、火、木、土。于是按生克：用神生它 → 旺（×1.40）；同气 → 旺（×1.25）；它生用神 → 平（×1.00）；用神克它 → 弱（×0.85）；它克用神 → 衰（×0.50，还添一分伤）。

财旺则名必弱，这是生克图的结构，不是数值调出来的。所以「哪个选择最优」取决于你要哪一种人生——要富家翁就吃伤，要儿孙满堂就弃财。

三、岁运：同一卦，十七岁与五十六岁读法不同

六节各有岁运五行（木火土金水土）。岁运与用神生克，决定当节的基调：运来生你 ×1.15、当运 ×1.25、你泄于运 ×0.90、运来克你 ×0.85。

所以这一节旺、下一节未必旺；同一个行当，在不同年纪分量不同。

四、卦只说这一步怎么走，不说结果好不好

卦辞本来就是命令句：「利涉大川」是叫你去，「勿用有攸往」是叫你停。这套判读直接从六十四卦原文按字面读出，不是另编的。

关键：卦意只改「折损率」，不改「收益」。它不告诉你这一节赚不赚，只告诉你该迈多大步子。

  • 宜进（利涉大川 / 利有攸往）：押重时折损大减（38%→21%），押轻时反而略增
  • 宜守（勿用 / 无攸利）：押轻时折损降到 6%，押重时涨到 70% 且额外添一分伤
  • 宜借（利见大人）：缘旺则折损降到 60%，缘衰则涨到 140%
  • 宜常：无特别嘱托，照常

五、卦会不应验，动爻就是变数

六爻皆静：卦语可信（应验约 88%）。一二爻动：信七分（68%）。动爻过半：卦乱，只有 45% 可信。

不应验时，整个卦是反的——说「宜进」的其实是「宜守」。所以你照着卦走，可能正走在反方向。界面只告诉你动了几爻，不告诉你准不准；准不准，要你自己掂量。

六、问卦是稀缺的

每世四次数额，而人生有六节。哪四节问，是你的判断。

七、负负得正

出生卦判为「下」或「下下」的命，去走摸金或经商（险行），系数拉到 ×1.4，还免一分伤——「命硬的人，走险路才不浪费」。

反过来，上上之命去走险行，只是白瞎（×0.9）。坏签不是让你重开，是给你另一套 build。

八、中西怎么合：各答一半，不抢同一个问题

两套系统如果都回答「这一节好不好」，那只能比谁更准，不能叫融合。所以分工是：

  • 中式问「该不该动」——卦辞说宜进、宜守、宜借
  • 西式问「动不动得动」——塔罗的五行与卦的用神生克，看手里有没有力

合起来就是四象限：

  • 该动 + 有力 → 天时在手，牌也有力，可押重
  • 该动 + 无力 → 天时对，手里却没牌，押了也白押
  • 宜守 + 有力 → 有牌，但天时不与，留着别急
  • 宜守 + 无力 → 天时不与，手里也没牌，别动

实测 30000 次，四象限分别占 29.7% / 12.2% / 30.7% / 27.3%——四种局面都常见，不是摆设。

九、死与结算

伤满 10 即亡，六节走完则收摊。终局算人生价值 = 财 + 名×2 + 缘×2 − 伤×5，换成资财，可买四项场外升级，留给下一世。
